# 오늘의 화분 — SY Lab 스케쥴러

하루 업무를 타임라인에 배치하면, 그날의 업무량에 따라 **식물이 싱싱해지거나 시드는** 연구실용 일일 플래너입니다.
`index.html` 파일 하나가 전부라서, 파일을 받아 브라우저로 열기만 하면 됩니다 (서버·설치 불필요).

## 사용법

1. **업무 박스 만들기** — 왼쪽에서 업무 이름 · 소요 시간 · 난이도(상=빨강, 중=노랑, 하=초록)를 정해 박스를 만듭니다.
   - Culture처럼 걸어두는 업무는 **🔁 돌려놓기(방치형)** 를 체크하세요.
2. **배치하기** — 박스를 타임라인에 **드래그 앤 드롭**하거나, 박스를 **클릭**해 날짜와 시작 시간을 직접 지정합니다.
   - 배치된 블록은 끌어서 옮기고, 아래 모서리를 끌어 시간을 조절하고, 클릭해서 분 단위로 수정할 수 있습니다.
   - 같은 시간대에 여러 업무를 겹쳐 배치할 수 있습니다 (배양 돌리면서 다른 실험 병행).
   - 자정을 넘는 업무는 다음 날 타임라인에 이어서 표시됩니다.
3. **식물 확인** — 그날의 **구속 시간**(겹치는 구간은 한 번만 계산, 돌려놓기 업무는 제외)에 따라:

   | 구속 시간 | 식물 상태 |
   |---|---|
   | 8시간 이하 | 싱싱해요 🌱 |
   | 8–12시간 | 살짝 시들었어요 |
   | 12시간 이상 | 완전히 시들었어요 🥀 |

## 저장

모든 데이터는 각자 브라우저의 localStorage에 저장됩니다. 다른 사람과 공유되지 않으며,
같은 브라우저로 다시 열면 그대로 남아 있습니다.
