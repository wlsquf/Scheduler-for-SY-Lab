# 오늘의 화분 — SY Lab 스케쥴러

하루 업무를 타임라인에 배치하면, 그날의 업무량에 따라 **식물이 싱싱해지거나 시드는** 연구실용 일일 플래너입니다.
`index.html` 파일 하나가 전부라서, 파일을 받아 브라우저로 열기만 하면 됩니다 (서버·설치 불필요).

## 기본 사용법

1. **업무 박스 만들기** — 왼쪽에서 업무 이름 · 소요 시간 · 난이도(상=빨강, 중=노랑, 하=초록) · 장소 · 간단한 설명을 정해 박스를 만듭니다.
   - Culture처럼 걸어두는 업무는 **🔁 돌려놓기(방치형)** 를 체크하세요.
   - 장소는 **Main Room, Cell Room**(고정) 외에 "장소 관리"에서 자유롭게 추가·삭제할 수 있습니다.
2. **배치하기** — 박스를 타임라인에 **드래그 앤 드롭**하거나, 박스를 **클릭**해 날짜와 시작 시간을 직접 지정합니다.
   - 배치된 블록은 끌어서 옮기고, 아래 모서리를 끌어 시간을 조절하고, 클릭해서 분 단위로 수정할 수 있습니다.
   - 같은 시간대에 여러 업무를 겹쳐 배치할 수 있습니다 (배양 돌리면서 다른 실험 병행).
   - 자정을 넘는 업무는 다음 날 타임라인에 이어서 표시됩니다.
   - **⚙ 자동 배치**: 선택한 박스들을 빈 자리에 자동으로 넣어줍니다. 점심 11:30–13:30, 저녁 17:30–19:30은 비워 두고 배치합니다 (돌려놓기 업무는 예외).
3. **식물 확인** — 그날의 **전업 시간**(겹치는 구간은 한 번만 계산, 돌려놓기 업무는 제외)에 따라:

   | 전업 시간 | 식물 상태 | 애니메이션 |
   |---|---|---|
   | 8시간 이하 | 싱싱해요 🌱 | 나비와 벌이 꽃에 날아와요 |
   | 8–12시간 | 살짝 시들었어요 | 바람에 살짝 흔들려요 |
   | 12시간 이상 | 완전히 시들었어요 🥀 | 파리가 꼬여요 |

## 테마

우측 상단에서 ☀️ 라이트 · 🌙 다크 · 🌸 꽃 세 가지 테마를 고를 수 있습니다.
제목 옆에는 자기 이름을 적어둘 수 있어요.

## 아카이빙과 내보내기

- 하루가 지나 페이지를 열면 **어제까지의 기록을 아카이빙할지** 물어봅니다.
- 아카이빙된 기록은 우측 상단 **🗂 보관함**에서 날짜별로 자세히 볼 수 있고,
  **HTML · Word · CSV · PDF**로 내보낼 수 있습니다 (PDF는 브라우저 인쇄 대화상자에서 "PDF로 저장").

## 주간 보고서

일주일을 잘 사용하면(기록 있는 날 3일 이상) 8일째 되는 날 **주간 보고서**가 뜹니다.
일주일 치 전업 시간과 식물 상태를 한눈에 보여주고, 시든 날이 3일 이상이면
식물이 시들어가는 애니메이션과 함께 **"적절한 휴식을 취해주세요!"** 라고 알려줍니다.
지난 보고서는 보관함에서 다시 볼 수 있습니다.

## 저장

모든 데이터는 각자 브라우저의 localStorage에 저장됩니다. 다른 사람과 공유되지 않으며,
같은 브라우저로 다시 열면 그대로 남아 있습니다.
